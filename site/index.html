01 / PHYSICAL

What is in the window?

Exact or estimated tokens, category share, source attribution, and declared context-window utilization.

02 / STRUCTURAL

What keeps accumulating?

Exact and near duplication, turn lifetime, replay count, replay PAU, and retention tax.

03 / UTILITY

What earns its keep?

Provided, heuristic, or experimentally calibrated utility remains explicitly labeled.

04 / CONTROL

What may be changed?

Protected context is observable but excluded from automated optimization candidates.

import {
  normalizeTrace,
  analyzeTrace,
  buildOptimizationPlan
} from "pau-profiler";

const trace = normalizeTrace(modelPayload, {
  contextWindow: 128_000,
  model: selectedModel
});

const receipt = analyzeTrace(trace);
const plan = buildOptimizationPlan(receipt, "balanced");

runtime.emit("context.receipt", receipt);
